# 🇭🇷 Croatia – Discover the Pearl of the Adriatic

A fully self-contained local website showcasing Croatia across seven rich sections.

## Project Structure

```
Croatia/
├── index.html        ← Main (and only) page
├── css/
│   └── styles.css    ← All styles (responsive, dark/light themed sections)
└── js/
    └── main.js       ← Interactivity (tabs, scroll effects, animations)
```

## Sections

| Section | Contents |
|---------|----------|
| **Hero** | Country overview with key stats |
| **Geography** | Terrain, coastline, islands, rivers, climate |
| **Politics** | Government, EU/NATO, CSS-drawn Croatian flag |
| **Nature** | 4 tabs: National Parks · Flora · Fauna · Marine Life |
| **Famous People** | Tesla, Bošković, Modrić, Kostelić, Ivanišević, Ružička and more |
| **Food** | 4 regional tabs: Dalmatia · Istria · Slavonia · Zagreb |
| **Curiosities** | 10 surprising facts (tie invention, Dalmatian dog, torpedoes…) |

## How to Open

**Option 1 – Direct open (no server needed)**
Double-click `index.html` to open it in your default browser.

**Option 2 – Live Server in VS Code**
1. Install the **Live Server** extension (`ritwickdey.liveserver`)
2. Right-click `index.html` → **Open with Live Server**
3. The page auto-reloads on every save

## Features
- Pure HTML5 / CSS3 / Vanilla JavaScript — zero external dependencies
- Fully responsive (mobile, tablet, desktop)
- Sticky navbar with active-section highlighting
- Tabbed UI for Nature and Food sections
- Scroll-triggered fade-in card animations
- CSS-drawn Croatian flag with šahovnica (chessboard coat of arms)
- Back-to-top button
